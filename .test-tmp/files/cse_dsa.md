# Data Structures - Binary Trees

A binary tree is a hierarchical data structure where each node has at most two children: a left child and a right child. The root is the topmost node. A leaf is a node with no children.

The height of a binary tree is the number of edges on the longest path from the root to a leaf. An empty tree has height -1, and a single-node tree has height 0.

A balanced binary tree minimizes height, giving O(log n) operations. An unbalanced tree can degrade to O(n).
